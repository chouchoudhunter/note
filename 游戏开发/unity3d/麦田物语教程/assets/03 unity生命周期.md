#### 1. 初始化阶段（只执行一次）

- **Awake()**
    
    - 最早执行，在脚本实例被创建时调用
    - 常用于初始化变量、获取组件引用（即使物体被禁用也会执行）
    - 同一 GameObject 上的多个脚本，Awake 执行顺序不确定
- **OnEnable()**
    
    - 当脚本被启用（勾选复选框）时调用
    - 可用于重置状态或重新注册事件（会在 Start 之前执行）
- **Start()**
    
    - 在第一帧更新之前调用，晚于 Awake
    - 适合编写需要依赖其他脚本 Awake 初始化完成后的逻辑
    - 同一 GameObject 上的多个脚本，Start 执行顺序不确定

#### 2. 帧更新阶段（每帧执行）

- **FixedUpdate()**
    
    - 固定时间间隔执行（默认 0.02 秒 / 次），与帧率无关
    - 专门用于物理计算（Rigidbody 相关操作），确保物理效果稳定
- **Update()**
    
    - 每帧执行一次，间隔时间不固定（取决于帧率）
    - 适合处理大部分游戏逻辑（输入检测、移动控制等）
- **LateUpdate()**
    
    - 在 Update 之后执行
    - 常用于跟随逻辑（如相机跟随角色，确保角色先移动再更新相机位置）

#### 3. 渲染阶段（每帧执行，在更新之后）

- **OnPreRender()**
    
    - 相机开始渲染前调用
- **OnRenderObject()**
    
    - 在相机渲染完所有物体后调用，可用于绘制自定义几何图形
- **OnPostRender()**
    
    - 相机完成渲染后调用

#### 4. 禁用 / 销毁阶段

- **OnDisable()**
    
    - 脚本被禁用时调用
    - 用于清理事件监听、保存临时状态
- **OnDestroy()**
    
    - 脚本实例被销毁时调用
    - 用于释放资源、取消订阅事件

#### 5. 其他重要方法

- **OnApplicationQuit()**
    
    - 应用程序退出时调用（编辑器中停止运行也会触发）
- **OnCollisionEnter/Stay/Exit()**
    
    - 碰撞检测相关（需要碰撞体和刚体）
- **OnTriggerEnter/Stay/Exit()**
    
    - 触发器相关（碰撞体勾选 Is Trigger）
- **OnGUI()**
    
    - 用于绘制旧版 GUI 界面，每帧可能执行多次
